## Codebase Patterns
- Target repos are separate: `aptabase-com` (Astro marketing site) vs `aptabase` (main app). Clone repos as needed.
- Astro serves `public/` directory at URL root — static files like `llms.txt` go in `public/`
- SDK framework list is defined in `aptabase-com/src/lib/frameworks.ts` with slugs, URLs, and code examples
- aptabase-com has no lint/test setup — only `astro build` for validation
- There are 16 SDKs across 12 repos (aptabase-js is a monorepo with 4 packages: web, react, angular, browser)
- NativeScript SDK is community-maintained at `nstudio/nativescript-plugins`, not under `aptabase/` org
- Docs pages are at `src/pages/docs/` as `.md` files (currently: build-modes.md, apple-app-privacy.md)
- Footer component is at `aptabase-com/src/components/Footer.astro`
- robots.txt is at `aptabase-com/public/robots.txt`
